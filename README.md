# Python Snake Game 🐍

A clean, modern Snake game created in Python using only the built-in standard library (`turtle`). No external packages or `pip install` commands are needed!

---

## 🎮 How to Run

Open your terminal or command prompt in this folder and run:

```bash
python snake_game.py
```

---

## 🕹️ Controls

| Action | Controls |
| :--- | :--- |
| **Move Snake** | Arrow Keys (`↑`, `↓`, `←`, `→`) or `W`, `A`, `S`, `D` |
| **Pause / Resume** | `Spacebar` |
| **Restart Game** | `R` (or `Spacebar` on Game Over screen) |
| **Quit Game** | `Esc` or `Q` |

---

## ✨ Features

- **Zero Dependencies**: Uses Python's built-in `turtle` module.
- **Modern Dark Theme**: Styled with a dark slate background, glowing emerald snake, and vibrant ruby food.
- **Input Buffering**: Prevents accidental self-collisions when pressing direction keys in rapid succession.
- **Score & High Score Tracking**: Displays live score and updates personal best high score.
- **Dynamic Difficulty**: Game speed progressively increases as your snake grows longer.
- **Pause & Instant Restart**: Ability to pause mid-run or immediately restart after game over.
